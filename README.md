# 꿀팁도사 — 정적 사이트 첫 버전

꿈해몽, 오늘의 운세, 주간운세, 생활꿀팁(부동산·이사·청소)으로 구성된 한국어 반응형 정보 사이트입니다.

## 브랜드 변경
- 기존 생활도사 시안의 브랜드를 **꿀팁도사**로 변경했습니다.
- 기존 꿈해몽·운세·부동산/이사/청소 정보 페이지와 자동화 구조는 유지했습니다.
- 공개 전에 실제 운영자 정보·개인정보처리방침·도메인을 정해주세요.

## 포함된 기능
- 4개 메뉴, 꿈해몽 8개·생활꿀팁 6개 독립 글 페이지 + 부동산·이사·청소 카테고리 3개
- 12띠 오늘의 운세·주간운세, 한국시간 기준 날짜별 내용 변경
- 제목·요약·시맨틱 HTML·기사 구조화데이터·목록 내부 검색·통합 검색
- 애드센스 자리(광고 스크립트는 아직 없음), 체인지클린 서비스 안내 영역
- 사이트 소개 / 개인정보처리방침 **초안** / 문의 페이지(Netlify Forms 사용)
- GitHub Actions 매일 KST 00:10 자동 재생성 워크플로(깃허브 스케줄 지연 가능)
- Netlify 배포 설정(netlify.toml)

## 로컬 실행
```bash
python3 build.py
python3 -m http.server 8000 --directory site
```
브라우저에서 http://localhost:8000 으로 접속합니다. `index.html` 파일을 직접 열면 절대경로 링크가 정상 작동하지 않을 수 있어 로컬 서버 실행을 권장합니다.

## 배포 순서
1. 새 GitHub 저장소에 `build.py`, `netlify.toml`, `site/`, `.github/workflows` 전체를 업로드합니다.
2. Netlify에서 GitHub 저장소 연결 → 빌드 명령 `python3 build.py`, 게시 폴더 `site`.
3. 사이트 주소를 확정한 뒤 Netlify 환경변수 `SITE_URL=https://YOUR-DOMAIN`으로 설정합니다. 사이트맵과 canonical URL이 생성됩니다.
4. 체인지클린 실제 홈페이지 주소가 확정되면 `CHANGECLEAN_URL=https://...`을 설정합니다.
5. 자동 업데이트용 GitHub 저장소 Variables에도 `SITE_URL`, `CHANGECLEAN_URL`을 설정합니다. Actions 쓰기 권한과 브랜치 보호 설정을 확인합니다.
6. 실제 운영자 정보, 개인정보처리방침, 문의 수신, 콘텐츠 검수 후 공개합니다.

## 운영상 주의
- 운세는 생년/시간 기반 개인 사주가 아닌, **12띠 오락용 창작 메시지**입니다. 개인의 운명을 보장하지 않습니다.
- 예시 콘텐츠는 초기 시연용이므로 전문적인 사실 검토, 차별화된 정보 확장, 날짜·출처 검토가 필요합니다.
- 현재 샘플 기사의 작성일은 2026-10-29로 고정해 자동 재배포만으로 게시일이 바뀌지 않도록 했습니다. 실제 운영할 때는 글별 실제 작성일·수정일을 별도로 관리하세요.
- 애드센스 승인은 별도 신청·심사를 받아야 하며 광고 자리만 있는 것으로 수익이 발생하지 않습니다.
- 문의 양식은 Netlify Forms 설정과 개인정보 보유기간·연락처 기입을 완료한 뒤 사용하세요.
- 사이트 URL 확정 전에는 `sitemap.xml`이 만들어지지 않습니다.

- 모든 페이지의 OG 이미지 태그를 추가했습니다. 공개 주소를 확정하면 `SITE_URL`을 등록해야 절대 경로를 사용할 수 있습니다.
- 도메인 연결, 광고 승인, 체인지클린 서비스 링크 연결은 아직 완료되지 않았습니다.
